# MYDOOM

Sparatutto in prima persona in 3D in stile Doom, realizzato con JavaFX.

## Comandi

| Tasto | Azione |
|-------|--------|
| W A S D | movimento |
| Mouse | visuale (orizzontale e verticale) |
| Click sinistro | sparo |
| ESC | esci dal gioco |

## Avvio

Con Java 17 o superiore:

```
mvn javafx:run
```

oppure da IntelliJ IDEA avviando la classe `com.example.Game`.
